# 典拠データベースの調査結果

## 要旨

VIAF・ISNI・GND・LCNAF・ULAN・Web NDL Authorities などの典拠(authority)データベースは、
著作物を残した人物を中心に収録される傾向があります。統治のみで著作のない藩主は収録されにくいと考えられます。

峰山藩初代藩主・京極高通について、下記のデータベースで項目が見つからないことを確認しました。

| 区分 | データベース |
|---|---|
| 国際的な典拠 | VIAF / ISNI / GND / LCNAF / ULAN |
| 国内の典拠・検索 | Web NDL Authorities / ジャパンサーチ / コトバンク |
| 系図・人物サイト | Geni / WikiTree / FamilySearch |

寛政重修諸家譜・寛永諸家系図伝には記載があるはずですが、個別にオンライン検索できる形では公開されていません。

## 含意

こうした人物については、Wikidata(およびそのソースになるWikipedia記事)が、
オンラインで参照できる数少ないデータ源になっています。
峰山藩主12代すべてについて、P214(VIAF)・P213(ISNI)・P349(NDL)・P227(GND)・P244(LCNAF)は
「調査済みで存在しない」ものとして空欄にしています。

## 注意

- 確認したのは京極高通についてで、他の藩主についても同様である旨は、上記識別子の検索結果に基づきます。
- 各データベースの調査日は記録していません。収録状況は変わり得るため、再確認が必要です。
