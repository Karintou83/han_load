# 江戸時代藩主のWikidata整備ツール(峰山藩を起点に)

江戸時代の藩主について、Wikidataの項目を整備するための調査記録とスクリプト集です。
最終的には、整備したデータから藩主の家系図を可視化するサイトを作ることを目指しています。

## 内容

- `code/create_han_lord_position.py` — 「○○藩主」の役職項目と各藩主の基本ステートメント、家系ドラフトを、
  QuickStatements V1形式のTSVとして生成するスクリプト。**Wikidataへの書き込みは行いません。**
- `code/*.tsv`, `code/*_report.txt` — 小城藩・鹿島藩・佐倉藩・赤穂藩・津山藩で生成した出力
  (ドラフトを含む。未レビューのものがあります)
- `docs/` — 調査結果とモデリング方針の解説
  - [`authority-databases.md`](docs/authority-databases.md): 典拠データベースの調査結果
  - [`modeling.md`](docs/modeling.md): Wikidataのプロパティ設計(家系・在職)
  - [`pipeline.md`](docs/pipeline.md): 他の藩へ横展開するためのパイプライン設計とQuickStatementsの運用メモ
  - [`status.md`](docs/status.md): 峰山藩主12代の基礎データと未解決事項

## 使い方(概要)

```
pip install requests
python code/create_han_lord_position.py prepare-han <藩名> <旧国名>
```

生成されたTSVは、**必ず内容を目視で確認し、数件だけ試し打ちしてから**
[QuickStatements](https://quickstatements.toolforge.org/) に貼り付けてください。
詳しい引数は `code/create_han_lord_position.py` 冒頭のdocstringを参照してください。

## 連絡先の設定(User-Agent)

Wikimediaの[User-Agent policy](https://foundation.wikimedia.org/wiki/Policy:Wikimedia_Foundation_User-Agent_Policy)に従い、
APIリクエストには連絡先を含めます。他の人が使う場合は、環境変数 `EDO_UA_CONTACT` に
**自分の連絡先(Wikipediaの利用者ページのURLなど)** を設定してください。未設定の場合は、作者の利用者ページが使われます。

```
# PowerShell
$env:EDO_UA_CONTACT = "https://ja.wikipedia.org/wiki/User:YourName"
# bash
export EDO_UA_CONTACT="https://ja.wikipedia.org/wiki/User:YourName"
```

- 家系関係(P22/P40/P1038/P1039)のドラフトは、Wikipediaの記載から機械的に作ったものです。

  (詳細は [`docs/status.md`](docs/status.md))。

## 個別の藩についてのメモ(東北の藩のTSV作成時)

- **湯長谷藩**: 初代・遠山政亮の在職は、湯長谷藩主としての1676年から始めています。これは、この藩がもともと湯本藩の藩主として始まったことに起因します(作者の説明)。
  政亮の湯本藩主時代(1670-1676)は、湯長谷藩主の在職からは外しました。湯本藩の項目は後で作り、その在職として別に入れる予定です。
- **矢島藩**: 途中で旗本になった時期があります。藩主として扱うのは
  生駒高俊(1640-1658)と生駒親敬(1868-1871)の2人のみです。
  旗本期の当主は在職(P1308)から外しましたが、親子・養子関係(P22/P40/P1038)は家系ドラフトに残しています。
- **黒石藩**: 最初は旗本でした。藩主として扱うのは
  津軽親足(1809-1825)・津軽順承(1825-1839)・津軽承保(1839-1851)・津軽承叙(1851-1871)の4人のみです。
  旗本期の当主は在職から外しましたが、家系ドラフトの親子・養子関係は残しています。
- **磐城平藩(要確認)**: 井上正経の退任と安藤信成の入封の年を、テンプレート上は1756年としています。
  根拠は、いわき市の資料(領主の変遷)に「宝暦6年(1756)5月に新領主として安藤信成が入封」とあることです。
  一方、日本語版Wikipediaの「井上正経」「磐城平藩」の記事は、井上氏の在任を宝暦8年(1758)まで、
  同年12月の浜松への転封としています(大坂城代・京都所司代の就任を挟むため、年がずれている可能性があります)。
  文献でさらに確認するまでは、1756年は暫定値です。
- **下手渡藩**: Template:下手渡藩主 がないため、東北46藩の一括投入には含めていません。九州の藩(三池藩など)を作成する際に一旦作成し、その後に改修する予定です(立花種善・種温・種恭の3代、1806〜1871)。
- **久保田新田藩・岩崎藩**: 「久保田新田藩」は名前が同じで実態の異なる2つの分家があります。役職項目は2つに分け、佐竹義都・義堅の系統(Q141657987)と、のちの岩崎藩の系統(Q141661611、佐竹義長〜義諶の8人)としています。岩崎藩という名称になった1869年以降の藩主は佐竹義理のみで、岩崎藩主(Q141661612)としました。藩の項目は岩崎藩(Q141654715)です。
- **白河新田藩**: 奥平松平家・太田松平家の2家がありますが、役職項目は1つ(Q141661504)にまとめています。藩の項目は Q12603905 です。
- **湯本藩**: 湯本藩(Q141661613)と湯本藩主(遠山政亮、1670-1676)を新規に作成しました。湯長谷藩主の在職は1676年からのままです。
- **左沢藩(Q141654806)・大山藩(Q141654758)**: 役職項目を作成しました(左沢藩主 Q141661695:酒井直次 1622-1630、大山藩主 Q141661696:酒井忠解 1647-1668)。
  Template:大山藩主 は酒井忠解の在職を1866-1869としていますが、庄内藩の記事(1647年立藩、1668年に嗣子なく収公)と藩の項目に合わせて1647-1668としています。Template側の誤記の可能性があります。

### 関東: Templateの年に「?」がある藩(2026-10-11)

Template:○○藩主 の年に「?」が付いている藩です。スクリプトは「年に付く『?』は外してその年を採用」「年が全く無い期間は開始・終了とも不明のまま残す」として扱います
(P580/P582は取れた年だけ付与。代数P1545は詰めない)。Template側の表記は以下のとおりで、「?」付きの年は不確実な年として扱ってください。

- **上野豊岡藩**(根津氏): 根津信政 `1602-?`、根津政次 `?-?`、根津信直 `?-1626`。
  根津信政は開始のみ(1602)、根津政次は年なし、根津信直は終了のみ(1626)で入る。
- **下総三浦藩**(三浦氏): 三浦重成 `1590-1624?`、三浦重勝 `1624?-1631`。
  交代年の1624は不確実だが、そのまま1624として入る。
- **玉縄藩**: 松平正綱 `1625?-1648`。開始年の1625は不確実だが、そのまま1625として入る。
  最初の一括生成では正綱が落ちて3名だけになり、代数がずれていた(P1545が1,2,3で、正綱の1625-1648が抜けていた)ため、`--force` で作り直す。

状態: 3藩とも、修正後のスクリプトでの再生成はまだ(2026-10-11時点)。上野豊岡藩・下総三浦藩はTSV未生成、玉縄藩のTSVは正綱が欠けた古いもの。
再生成後に、各藩の `*_position_create.tsv` の年を確認すること。

### 関東: 烏山藩・古河藩・岩富藩(2026-10-11)

## 抜け漏れ確認用のSPARQLクエリ(2026-10-14)

藩の項目(`P31`=藩)ごとに `P2388`(組織長の地位)の値を一覧表示する。値がない藩も残し、抜けが先頭に来るように並べる。Wikidata Query Service(https://query.wikidata.org/)で実行する。

- 「藩」クラスはQIDを直書きせず、日本語版Wikipediaの記事「藩」のサイトリンクから特定している。QIDが分かっていれば `VALUES ?hanClass { wd:Q○○○ }` に置き換えると速い。
- `wdt:P31/wdt:P279*` でサブクラス(新田藩など)も拾う。厳密に「藩」だけにするなら `wdt:P31 ?hanClass` にする。
- `P2388` が複数ある藩は複数行になる(重複・改称前後の役職の混在の確認にも使える)。
- 注意: 作成時点ではWDQSに接続できず、実行して確認していない。初回は結果の件数と先頭の数行を確認する。

```sparql
SELECT ?han ?hanLabel ?pos ?posLabel ?jawiki WHERE {
  ?hanClass ^schema:about ?clsArticle .
  ?clsArticle schema:isPartOf <https://ja.wikipedia.org/> ;
              schema:name "藩"@ja .
  ?han wdt:P31/wdt:P279* ?hanClass .
  OPTIONAL { ?han wdt:P2388 ?pos . }
  OPTIONAL {
    ?jawiki schema:about ?han ;
            schema:isPartOf <https://ja.wikipedia.org/> .
  }
  SERVICE wikibase:label { bd:serviceParam wikibase:language "ja,en". }
}
ORDER BY (BOUND(?pos)) ?hanLabel
```
